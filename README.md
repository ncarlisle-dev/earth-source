# earth-source

## How to run

**1. Open a terminal and run the following command to clone into this branch of the repository**
```bash
git clone -b readme-and-auth https://github.com/ncarlisle-dev/earth-source.git
```

**2. Navigate to the src directory within the repository**
```bash
cd earth-source/src
```

**3. Run the app**
```bash
flutter run
```

**4. Select the device to run the app on from the given options**

**5. Once the app starts running, click the login button to enter the app.**

Important Note: As authentication hasn't been implemented for this app yet, the login button doesn't do
anything at the moment. Users will **not** be authenticated, and consequently the same projects, data files,
etc. will be visible to all users testing the app.

**6. Navigate to the help page for instructions on how to use the app.**
